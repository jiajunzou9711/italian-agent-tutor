# Daily Briefing Configuration

Enabled: To be asked

Primary Interest: To be asked

Backup Interest: None

Current Facts Policy: Use current facts only after verifying them with a reliable source.

No-Web Fallback: Use level-controlled evergreen material and explicitly say it is not current news.

Difficulty: Match the working level and introduce at most a small amount of uncertain language.

Purpose:

- Lower the cost of starting a session with a genuinely interesting Italian paragraph.
- Ask for the gist before explaining it.
- Carry two or three useful words into the main line when they fit the learning target.

Boundary:

- The briefing supplies context and motivation; it never overrides the main learning target.
- Topic complexity never justifies grammar far above the learner's working level.
